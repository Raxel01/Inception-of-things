Vagrant commands :
   vagrant box : manipulate and manage boxes
   vagrant destroy [ID]: stop[shutdown] &&cleanup Vms and Resources allocated while starting the vm
   vagrant global-status: state of all active vagrant Environ
   vagrant halt [ID]: shutdow the VM vagrant is running
   vagrant init : create a vagrant environment
   vagrant Login: authenticate to varant cloude
   vagrant package: create a snapshot resulting .box file to share with developers
   vagrant port: list of guet ports mapped to host machine ports
   vagrant reload: running halt and up when you did any changes to the vagrant file
         - it does n't run --provision budefault .
   vagrant resume managed machine that was prev suspended
   vagrant snapshot: manage VM snapshots.
   vagrant ssh: connect to the guest machine by SSH
